# 土建图纸全流程工程技能包

## 用途

把成套土建施工图转化为可追溯、可复核的工程成果：图纸台账、会审问题清单、工程量计算书、施工图预算、危大工程专项方案、安全与签证管理文件、技术交底、竣工归档清单。全流程以「图号 + 位置」为索引，任何结论都必须能回到图纸原文。

## 首要约束（适用于所有阶段，不可逾越）

1. 以图纸为唯一事实源。禁止凭记忆补写尺寸、标高、配筋、混凝土强度等级、轴线编号或规范条文号。图上没有时，明确写「图纸未注明，待设计确认」，不得推测填充。
2. 逐条结论必须可追溯：标注图号、图名、出图日期/版本，以及轴线、构件编号或详图索引等定位信息。无定位的结论标记为「待定位」。
3. 先定版本再干活。开工前确认图纸版本、出图日期、是否作废、有无设计变更/洽商已替代；作废图纸只可作历史对照，不得用于算量或交底。
4. 区分事实与判断。「图上标注为 C30」是事实；「该标注不满足耐久性要求」是判断。判断须写明依据、适用条件与置信度，并与事实分栏呈现。
5. 算量必须独立二次校核。给出计算式、扣减规则、单位、来源图号与置信度；不得把估算表述为精确值，不得省略损耗或措施项目的口径说明。
6. 严守责任边界。涉及结构安全、地基基础、消防、抗震、强制性条文的结论只作为 AI 初审意见，输出时附「须由注册结构/建筑师及相关责任主体复核签认」提示；不代替设计、审图、监理、造价咨询的法定职责。
7. 统一口径：长度 mm 或 m（全文一致）、面积 m²、体积 m³、重量 kg/t；混凝土等级、钢筋级别、抗震等级、保护层厚度一律按图或按图纸说明所引图集。
8. 造价与定额数据不得编造：天津市定额子目编号、预算基价、人材机单价、费率、信息价期号、调整系数、危大工程判定阈值、安全限值与规范文号一律取本地现行有效文本或用户提供的文件；缺失时标「待核」，含待核项的成果不得作为招标控制价或结算依据。

按用户意图进入对应阶段；跨阶段任务按 S0→S5 顺序推进，不跳步。

## 各阶段公共动作

- **S0 收图清点**：建立图纸台账（图号、图名、专业、比例、版本、出图日期、张数、状态），核对目录与实收，标注缺图与作废图，输出 `assets/drawing_register_template.csv` 的填充版。用 `scripts/validate_drawing_register.py` 校验必填项、图号重复与版本冲突。
- **S1 识读索引**：按「设计总说明 → 平面图 → 立面/剖面 → 详图 → 结施平法」顺序通读，为每张图写一页索引（表达内容、关键尺寸、标高、材料、索引到的详图）。扫描件先确认可读性与比例，不可辨认处标「待核」。
- **S2 会审**：按「专业内一致性 → 专业间冲突 → 规范与强条 → 可施工性」顺序逐张过，每条问题记录图号、位置、图上原文、问题类型、严重程度、建议处理、责任方、状态。分级为 A（影响安全或强制性条文）、B（影响施工或造价）、C（表达与标注瑕疵）。
- **S3 算量**：先锁定计算范围与版本，分构件列式，执行扣减规则，再做独立二次校核，输出带来源与置信度的计算书。
- **S3b 预算**：以已复核的计算书为唯一工程量来源，做清单/定额口径换算、子目套用（编号与基价待核）、人材机价差、按天津市现行费用定额取费、三级汇总、独立校核；输出 `assets/tianjin_budget_template.md` 填充版与工程量来源对照表。
- **S4a 危大**：从图纸识别深基坑、高支模、大跨度、吊装等信号 → 出「疑似」初筛 → 由责任主体确认 → 涉及则补专项方案（计算书须由有资格人员编制复核）→ 审批、专家论证、交底、验收、归档。阈值与文号待核。
- **S4b 安全**：按部位列「技术措施 / 管理措施 / 检查验收 / 应急处置」四层，安全交底与技术交底分开签发；危大部位须先有已审批专项方案。
- **S4c 签证**：一事一签、先确认后实施、九步闭环；签认后回写 S0 台账、S3 计算书、S3b 预算及交底状态，并列入 S5 移交清单。
- **S4 文件编制**：从已确认的图纸事实和已闭环的会审结论取材，套用 `assets/` 模板；未闭环问题不得作为交底依据写入。
- **S5 归档**：汇总有效版本图纸、变更与洽商、会审记录、计算书、预算书、危大专项方案与安全记录、签证台账、交底记录，生成竣工图编制依据清单与资料移交清单。

## 输出与复核

每份成果固定包含：项目与单体名称、采用的图纸版本与出图日期、依据图号清单、编制日期、复核状态、未决事项清单。凡含判断或数值的结论，附置信度说明与「须由相应责任主体复核」提示。交付前逐项自检：版本是否最新、每条结论是否有图号、单位是否统一、待核项与未决项是否全部列出、危大工程是否已判定且方案已审批、签证是否已回写算量与预算。
