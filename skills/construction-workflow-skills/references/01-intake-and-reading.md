# S0 收图清点与版本控制 / S1 图纸识读与索引

## S0：收图清点

### 建立图纸台账

先复制 `assets/drawing_register_template.csv`，逐张录入下列字段。不得凭目录推断实收张数，目录与实收必须逐条比对。

| 字段 | 填写要求 |
| --- | --- |
| drawing_no | 图号，原样抄录，含专业前缀与序号，如 `结施-05` |
| title | 图名，原样抄录 |
| discipline | 建筑 / 结构 / 给排水 / 暖通 / 电气 / 幕墙 / 精装 / 总图 |
| scale | 图上标注比例；无比例写「示意图」 |
| version | 版本号或修订号，如 `A`/`B`/`Rev.2`；无则写「未标注」并列入待核 |
| issue_date | 出图日期，取图签日期，不取文件修改时间 |
| sheets | 该图号实收张数 |
| status | 有效 / 作废 / 待补 / 待核 |
| supersedes / superseded_by | 被替代关系，填图号或变更令编号 |
| remarks | 缺页、模糊、云线修订、加盖审图章等异常 |

### 成套性检查

按专业核对是否齐全，缺项写入台账 `status=待补`，并在成果中单列「缺图清单」。

- 建筑：设计总说明、总平面、各层平面、屋顶平面、各向立面、剖面、楼梯详图、墙身/节点详图、门窗表与门窗详图、防火分区、节能设计、室内做法表
- 结构：结构设计总说明、基础平面与详图、柱/墙配筋平面、各层梁配筋平面、板配筋平面、楼梯详图、节点构造详图、预留洞与预埋件图
- 对照专业（用于查冲突，不用于土建算量）：给排水、暖通、电气、幕墙、精装、电梯、设备基础

### 版本判定优先级

按下列顺序判定有效版本，冲突时列「待设计确认」，不得自行择一：

1. 设计变更 / 工程洽商中明确作废或替代的图号
2. 图签内的出图日期与版本号、修订云线及修订说明
3. 审图机构盖章版、施工图审查意见回复后的修改版
4. 图纸目录与实收张数的一致性

作废图仅在 `status=作废` 下保留作历史对照，S3 算量与 S4 交底一律禁用。

### 台账校验

执行 `python scripts/validate_drawing_register.py <台账.csv>`，检查必填项缺失、图号重复、版本号冲突、作废图仍被引用、日期格式错误。校验报告随成果一并交付；报错项未闭环前不得进入 S2/S3。

## S1：识读与索引

### 读图顺序

设计总说明 → 总平面与定位 → 各层平面 → 立面与剖面 → 节点详图 → 结构总说明 → 基础 → 竖向构件 → 水平构件 → 楼梯与节点。每张图读完即写一页索引，全部读完再开始交叉比对。

### 图纸索引表字段

| 字段 | 说明 |
| --- | --- |
| drawing_no / title / version | 与台账一致 |
| main_content | 该图表达的对象与范围 |
| key_dimensions | 总尺寸、定位尺寸、细部尺寸（保留三道尺寸链概念） |
| levels | 本图涉及的标高，注明建筑标高或结构标高 |
| materials | 混凝土等级、钢筋级别、砌体/砂浆、防水与保温材料 |
| cross_refs | 索引到的详图号、引用到的其他图号 |
| open_questions | 未看清、矛盾、待设计确认之处，逐条列 |
| status | 已读 / 待核 |

### 建筑图识读要点

- 三道尺寸链：总尺寸、轴线定位尺寸、细部尺寸；核对是否闭合，不闭合时标「尺寸链不闭合，待核」。
- 标高体系：区分建筑标高与结构标高，核对楼地面建筑做法厚度造成的高差；屋面找坡标高与结构板标高不可混用。
- 墙体：材料、厚度、轴线定位（居中或偏心）、墙身详图索引；注意平面与墙身详图厚度是否一致。
- 门窗：洞口尺寸、编号与门窗表一致性、过梁与构造柱设置、洞口与结构梁边关系。
- 防水与保温：地下室、屋面、卫生间、外墙的做法索引与翻边高度，核对索引号是否存在对应详图。
- 防火：防火分区、疏散宽度、防火门等级、防火墙与幕墙层间封堵。
- 楼梯：踏步、平台、梯段净高、栏杆高度、结构梯板与建筑面层关系。

### 结构图识读要点

- 平法图集版本以结构设计总说明为准（如 22G101 系列），不得默认某一版；总说明未写时列「待核」。
- 集中标注与原位标注冲突时，按图纸说明的优先规则处理；无说明时记录冲突并提请设计确认，不自行取值。
- 构件编号规则、梁/柱/板/墙截面与配筋、箍筋加密区、附加横向钢筋、吊筋，逐项与详图核对。
- 混凝土强度等级按构件、按楼层分别记录；同一构件不同图出现不同等级时列为 A 级问题。
- 抗震等级、保护层厚度、锚固与搭接长度、后浇带与施工缝位置，按总说明记录并注明依据页。
- 基础：基础形式、埋深、持力层与承载力、垫层、基坑支护与降水要求；核对与地质勘察报告是否对应（报告未提供时标「待提供」）。

### 常见易错点

建筑标高与结构标高混用；轴线偏心未识别；梁板标高差与主次梁交接；洞口过梁/构造柱遗漏；预留洞、预埋件与设备基础未对照；后浇带跨越不同图表达不一致；修订云线内内容未同步到相关图。

### 扫描件与 PDF 处理

先按图号拆页与命名，逐张确认可辨认性与比例。文字识别结果只作检索辅助，尺寸数字、标高、配筋必须回看原图核实。图上数字不可辨认时标「不可辨认，待核」，禁止用相邻构件数值类推。
