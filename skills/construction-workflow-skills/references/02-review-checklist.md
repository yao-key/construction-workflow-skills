# S2 图纸会审与问题台账

## 会审前准备

进入会审前必须已具备：有效版本台账（S0）、逐图索引（S1）、缺图清单、相关专业图纸。版本未锁定或索引未完成时，先补齐再会审。

## 检查顺序

按「专业内一致性 → 专业间冲突 → 规范与强制性条文 → 可施工性」逐张推进，每类问题分别记录，不混在一栏。每张图必须走完四类检查，即使无问题也记录「已过，无问题」。

### 1. 专业内一致性

- 图与目录、图与图签：图号、图名、版本、张数是否一致
- 平面与立面/剖面：外形、层数、标高、门窗位置是否对应
- 平面与详图：墙身、节点、楼梯、门窗详图的尺寸与做法是否对应平面标注
- 尺寸链是否闭合；总尺寸与分尺寸之和是否相符
- 同一构件在不同图的截面、配筋、混凝土等级、标高是否一致
- 材料表、门窗表、构件表与图上标注是否一致
- 索引号是否有对应详图，详图号是否有对应平面索引
- 修订云线内容是否已同步到所有相关图纸

### 2. 专业间冲突矩阵

| 对照方 | 高频冲突点 |
| --- | --- |
| 建筑 ↔ 结构 | 墙柱轴线偏心、梁下净高、板厚与建筑面层、洞口过梁、构造柱位置、楼梯梯板与建筑踏步 |
| 结构 ↔ 给排水/暖通/电气 | 穿梁套管与洞口、设备基础与基础/楼板、配电房与电缆沟、桥架与梁底净高、卫生间降板与管井 |
| 建筑 ↔ 幕墙/精装 | 预埋件位置、层间封堵、收口节点、洞口尺寸与分格 |
| 建筑 ↔ 电梯/设备 | 井道尺寸、机房高度、基坑深度、吊装口与运输通道 |
| 总图 ↔ 单体 | 室外地坪标高、±0.000 绝对标高、管线接口、消防车道与登高面 |

对照专业图纸缺失时，不写「无冲突」，写「缺 ×× 专业图纸，该项未核」。

### 3. 规范与强制性条文

按 `references/05-closeout-and-standards.md` 的引用规则执行。检查对象包括但不限于：防火分区与疏散、结构安全与抗震构造、地基基础、防水等级与构造、节能、无障碍、防护栏杆与临边、地下室抗浮。

仅在能指向本地有效规范文本或图纸明确依据时给出「不符合」结论；否则写「依据不足，需人工复核」，不得凭记忆写条文号。

### 4. 可施工性

施工顺序是否可行、模板与支撑空间、钢筋密集区能否浇筑、构件运输与吊装、施工缝与后浇带位置、预留预埋是否可实施、材料规格是否市场可得、工序之间是否互相破坏（防水与后续开洞等）。

## 问题分级

| 级别 | 判定 | 处理要求 |
| --- | --- | --- |
| A | 影响结构安全、消防安全、强制性条文，或导致无法施工 | 必须设计书面答复后方可进入 S3/S4；成果中显著列出 |
| B | 影响造价、工期或需变更做法，但不涉及安全 | 闭环后用于算量与交底；未闭环按暂估值处理并标注 |
| C | 标注、表达、索引、图面瑕疵 | 记录并统一在会审记录中提出，不阻断后续 |

## 问题台账字段

复制 `assets/issue_log_template.csv`，逐条录入：问题编号、图号、图名、版本、位置（轴线/构件编号/详图号）、图上原文、问题类型、级别、描述、建议处理、责任方、提出日期、设计答复、答复日期、状态、关联变更令编号、复核人。

状态流转：`提出 → 已送设计 → 已答复 → 已确认 → 关闭`；需变更的转 `转变更` 并填入变更令编号。未闭环问题在最终成果中单列「未决事项」，不得静默丢弃。

## 会审记录编制

复制 `assets/review_minutes_template.md`。正文按图号顺序组织，每条包含「图上原文 / 问题 / 建议 / 设计答复」四段；末尾汇总 A/B/C 各级数量、未决事项清单、缺图清单、采用的图纸版本清单。会审记录为过程文件，不得替代设计单位正式的图纸会审纪要或审图意见回复。

## 反模式

- 不得用「关键词匹配」代替逐张读图判断，图名相同不代表内容相同。
- 不得把「图上未见」等同于「没有」；未见时标「未见，待确认」并注明检索范围。
- 不得把推测写成结论；判断与事实必须分栏。
- 不得对 A 级问题自行给出处理方案后直接用于算量。
