# S3 土建工程量计算

## 前置条件（缺一不可）

1. 有效版本台账已锁定，作废图已排除；采用版本与出图日期写入计算书封面。
2. 计算范围已界定：单体、楼层、构件类型、±0.000 上下划分、是否含措施项目。
3. 计量口径已确定：按清单计价或定额计价、扣减规则、损耗与预留是否计入，全文一致。
4. A 级会审问题已闭环；B 级未闭环项按暂估值列入并显著标注，不参与汇总定值。

## 通用列式规范

每个构件一行，固定列：序号、构件编号/轴线位置、图号、计算式（含代入数值）、单位、小计、扣减说明、置信度、备注。计算式必须可复算，禁止只给结果。长度统一 m（保留 3 位）或 mm，面积 m²，体积 m³，钢筋 kg/t；同一份计算书只用一种长度单位。

## 分构件口径

| 项目 | 单位 | 计算与扣减要点 | 常见漏项 |
| --- | --- | --- | --- |
| 土方（挖/填/外运） | m³ | 按基础平面与垫层外扩工作面、放坡或支护口径；扣减重叠区域；室内回填扣基础与地下构件占体积 | 工作面与放坡口径未写明、地下水与支护另列 |
| 垫层 | m³ | 按基础外扩尺寸 × 厚度，逐基础/满堂分别列 | 集水坑、电梯基坑加深 |
| 混凝土基础 | m³ | 独立/条形/筏板分别列；扣后浇带、集水坑重叠；不扣钢筋与预埋件 | 基础梁与筏板重叠、柱墩、翻边 |
| 混凝土柱/墙 | m³ | 按楼层与截面分组；柱高取板底/梁底按图；墙扣门窗洞口 >0.3 m² 者（按口径） | 构造柱、抱框柱、女儿墙、墙与梁重叠 |
| 混凝土梁/板 | m³ | 梁长按柱/墙净距按图口径；板扣梁占体积或按板净面积×板厚，口径二选一且全文一致 | 主次梁交接、悬挑板、降板区、后浇带 |
| 模板 | m² | 按混凝土接触面计，扣减与混凝土口径对应；梁板底模与侧模分开列 | 基础侧模、构造柱、后浇带模板、超高支撑另列 |
| 钢筋 | kg / t | 按平法与图纸说明计算锚固、搭接、弯钩、加密区；分构件分规格列；不定参数列「待核」 | 措施筋、马凳、拉结筋、洞口加强筋、预埋件 |
| 砌体 | m³ | 按墙体净面积 × 墙厚，扣门窗洞口、构造柱、圈过梁；区分材料与砂浆等级 | 导墙、塞缝、顶部斜砌、不同材料交接 |
| 门窗 | m² / 樘 | 按门窗表与洞口尺寸核对，两种单位择一 | 过梁、窗台压顶、洞口侧壁抹灰 |
| 防水/保温 | m² | 按屋面/地下室/卫生间分别列，含翻边与附加层展开面积 | 阴阳角附加层、搭接、收头 |
| 装饰 | m² | 按做法表分层列，扣洞口规则写明 | 踢脚、门窗侧壁、零星抹灰 |
| 楼梯 | m² / m³ | 按图示梯段与平台，注明按投影面积或体积计 | 梯梁、平台板、栏杆预埋 |

## 钢筋计算规则

- 图集版本、抗震等级、混凝土强度等级、保护层厚度、锚固与搭接长度一律取自结构设计总说明；总说明缺失时标「待核」，不按默认图集取值。
- 集中标注与原位标注不一致时按说明优先规则；无规则时列为 A 级问题，暂按较不利值估算并标注「暂估，待设计确认」。
- 分规格（HPB300/HRB400 等按图）汇总，输出规格汇总表；措施筋与实体筋分列。
- 不得把钢筋下料长度与预算长度混用，计算书中注明属于哪一口径。

## 独立二次校核（必须执行）

交付前完成下列校核，校核结果写入计算书末节：

1. **总量平衡**：分层分量之和 = 单体总量；混凝土分量与模板、钢筋分量按同一构件范围对应。
2. **指标校核**：含钢量（kg/m³ 混凝土）、模板含量（m²/m³ 混凝土）、砌体与混凝土比值，与同类工程常规区间比对；显著偏离时回查计算式，不直接调整结果。
3. **独立复算**：换一种分组口径（如按轴线分区 vs 按构件类型）重算至少一个主要分项，差异超出口径允许范围时列出差异原因。
4. **来源核对**：随机抽取不少于 5 条计算式，逐条回看原图图号与数值，确认抄录无误。

## 置信度与表述

每个汇总值标注置信度：高（图注完整、双校核通过）、中（部分参数暂估或待核）、低（缺图/口径未定）。含暂估项的汇总必须写「含暂估，不可作为结算依据」。禁止把估算写成精确值，禁止省略单位或口径说明。

## 责任边界

计算书为 AI 初审或辅助成果，输出末尾附「须由造价人员及相应责任主体复核签认」，不作为结算、招标控制价或签证依据。复制 `assets/quantity_takeoff_template.md` 生成计算书骨架。

## 与施工图预算的衔接

计算书是 S3b 预算编制的唯一工程量来源。移交预算阶段时同时提供：计算书电子版、口径说明（清单/定额、扣减规则、单位制）、分项与汇总表、二次校核记录、未决与暂估项清单。预算阶段会发生定额口径换算（如 10 m³、100 m² 单位）与扣减规则调整，须在 `06-tianjin-budget.md` 的「工程量来源对照表」中逐项列出差异及原因，不得直接把计算书数值当作预算工程量。
