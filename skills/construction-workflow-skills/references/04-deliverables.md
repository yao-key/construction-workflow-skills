# S4 技术文件编制

## 取材规则

编制任何文件前先确认素材来源，四类来源按优先级使用：

1. 有效版本图纸原文（图号 + 位置）
2. 已闭环的会审结论与设计书面答复
3. 已签认的设计变更、工程洽商
4. 图纸设计说明中明确引用的规范与图集

未闭环问题、口头文件、推测数值、作废图纸一律不得写入正文；确需提示时放入「待确认事项」章节。文件中每处技术参数后括注依据图号，如「板厚 120 mm（结施-08，3~5/A~C 轴）」。

## 会审记录 / 会审问题汇总

使用 `assets/review_minutes_template.md` 与 `assets/issue_log_template.csv`。按图号顺序编排，每条四段式：图上原文 → 问题描述 → 建议处理 → 设计答复。A 级问题单列章节并标红或加「★」。末尾固定包含：分级统计、未决事项、缺图清单、采用版本清单、参与单位与日期栏。文件性质标注「过程记录，不替代设计正式会审纪要」。

## 技术交底记录

使用 `assets/technical_briefing_template.md`。必须写全以下章节，缺项标「待补」，不得用「按规范施工」「按图施工」之类空话代替：

| 章节 | 内容要求 |
| --- | --- |
| 工程与作业范围 | 单体、楼层、轴线范围、工程量、采用的图纸版本与出图日期 |
| 依据 | 图号清单；规范只写名称与版本，条文号按 `references/05-closeout-and-standards.md` 规则处理 |
| 作业条件 | 上道工序验收要求、基层条件、测量放线、材料进场检验状态 |
| 材料与机具 | 规格、等级、配合比或型号，均按图或已批准材料报审 |
| 工艺流程 | 按工序编号逐步写，每步写明操作对象与完成标志 |
| 质量标准 | 允许偏差、检验方法、检查频次；数值须有依据 |
| 安全与环保 | 临边洞口、支撑体系、吊装、用电、扬尘与废弃物 |
| 成品保护 | 交叉作业时的保护措施与禁止事项 |
| 常见问题 | 结合 S2 会审中该部位的问题给出预防动作 |
| 签认 | 交底人、接收班组、日期、复核人栏 |

交底对象按工种区分（钢筋、模板、混凝土、砌体、防水），一份交底只覆盖一个工种与一个作业段，避免混写。

## 工程联系单 / 洽商记录

字段：编号、提出单位、接收单位、日期、涉及图号与位置、事由（图上原文 + 现场条件）、建议处理、需答复时限、附件清单、签认栏。事由中区分「图纸问题」与「现场条件变化」，两者不得合并。涉及费用或工期的一律注明「费用与工期另按合同程序办理」。

## 设计变更台账

复制台账字段：变更令编号、收文日期、来源、涉及图号与版本、变更内容摘要、作废/替代图号、影响专业、是否影响已完工程、是否需重新算量、交底是否已更新、状态。收到变更令后同步执行三件事：更新 S0 图纸台账的版本与作废关系、标记 S3 计算书中受影响分项为「需重算」、标记相关交底为「需重新交底」。

## 文风要求

用祈使句和可执行动作（「支设前复核轴线偏差 ≤…」），不用模糊表述（「尽量」「原则上」「视情况」）。同一文件内术语、单位、构件编号与图纸完全一致。数字与日期不留占位符；确实未知的写「待设计确认」并列入待确认事项。

## 扩展交付物（新增能力）

本阶段除四类基础文件外，还需按项目情况补充下列成果，各自有独立参考文档与模板：

| 成果 | 触发条件 | 参考与模板 |
| --- | --- | --- |
| 施工图预算书（天津市定额计价） | S3 算量完成且需套价 | `06-tianjin-budget.md` / `assets/tianjin_budget_template.md` |
| 危大工程判定台账与专项施工方案 | 图纸存在深基坑、高支模、大跨度、吊装等信号 | `07-hazardous-works.md` / `assets/hazardous_works_register.csv` |
| 安全管理重点与措施表、安全技术交底 | 所有项目 | `08-safety-management.md` / `assets/safety_control_plan_template.md` |
| 现场签证单与签证台账 | 发生合同外事项、变更或现场条件差异 | `09-variation-claims.md` / `assets/variation_claim_register.csv` |

专项方案须先完成判定与审批，未审批部位不得写入技术交底的可施工范围；签证与变更引起工程量或做法变化时，须回写 S0 台账、标记 S3 计算书「需重算」并更新预算。

## 交付前自检

- 每处技术参数是否可回溯到图号与位置
- 采用版本是否为最新有效版本
- 未闭环问题是否全部进入「待确认事项」而非正文
- 单位、术语、构件编号是否与图纸一致
- 是否附「须由相应责任主体复核签认」提示
- 危大工程是否已判定、专项方案是否已审批
- 签证是否已回写算量、预算与交底状态
