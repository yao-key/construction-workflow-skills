# S3b 依据算量结果套用天津市定额编制施工图预算

## 适用范围与前置条件

在 S3 工程量计算书完成并通过独立二次校核后，将算量结果转换为以天津市现行计价依据套价的施工图预算。进入本阶段前须具备：有效版本图纸台账、已复核的工程量计算书、明确的合同计价方式与约定、工程所在地为天津市的确认。

**首要禁令**：天津市定额子目编号、预算基价、人材机单价、费率、调整系数、信息价期号、文件文号一律不得凭记忆填写。只能取自本地现行有效文本或用户提供的文件；无法取得时写「待核」，并在预算书中标「含待核项，不可作为招标控制价或结算依据」。本条是 `05-closeout-and-standards.md` 引用原则在造价数据上的延伸。

## 从算量结果到预算的六步

### 1. 口径转换（最易出错）

- 清单计量口径与定额计量口径常不一致：定额子目常以 10 m³、100 m²、t、10 个等为单位，而 S3 计算书以 m³、m²、kg 计。逐项记录换算系数，换算后回算一次验证。
- 核对定额子目「已包含的工作内容」与图纸做法：如混凝土子目是否含泵送、模板是否另列、钢筋是否含措施筋、防水是否含附加层。未包含的做法需补充子目或按定额说明换算，不得重复计价或漏项。
- 扣减规则差异：S3 的扣减口径与定额工程量计算规则不一致时，按定额规则重算并在计算书中并列两套数值，注明差异原因。

### 2. 子目套用

按「构件类型 → 做法与材料 → 施工方法 → 定额章节」逐级匹配；一个清单项可对应多个定额子目。混凝土强度等级、砂浆配合比、厚度、运距等与定额取定不同时，按定额说明做换算（换算系数与换算式取自定额文本，标待核）。匹配不确定时列「子目待核」，不强行套用相近子目。

### 3. 人材机价差

按合同约定与天津市信息价（或经批准的市场询价）调整；区分可调整与不可调整范围，材料规格、品牌、产地按图纸与材料报审记录。信息价期号与适用区间写入编制说明，缺期号时标待核。

### 4. 取费

按天津市现行费用定额的取费程序依次计取：分部分项工程费 → 措施项目费（区分单价措施与总价措施，安全文明施工费等不可竞争费用单列）→ 其他项目费 → 规费 → 税金。费率、计费基数、是否含税计价一律按现行文件与合同约定；不得凭记忆填费率。暂列金额、暂估价、计日工按合同约定列示。

### 5. 汇总

分部分项 → 单位工程 → 单项工程 → 建设项目三级汇总，附单位工程汇总表与主要材料表。每一级汇总与下级分项之和做平衡校核。

### 6. 独立校核

- 预算工程量与 S3 计算书逐项对照，差异逐条说明（定额口径换算、扣减规则、补充子目）
- 单方造价、主要材料含量（混凝土 m³/㎡、钢筋 kg/㎡、模板 m²/㎡）与同类工程指标比对，显著偏离时回查而非调数
- 换一种取费顺序或分组方式复算至少一个单位工程，记录差异
- 抽验不少于 5 条子目，回看定额文本与图纸做法，确认换算与套用无误

## 预算书结构

复制 `assets/tianjin_budget_template.md`，固定包含：封面（项目、单体、采用图纸版本、编制日期、编制/复核）、编制说明（依据清单与版本状态、计价口径、换算规则、待核项清单）、单位工程汇总表、分部分项计价表（含子目编号待核列）、措施项目表、人材机汇总与价差表、取费表、主要材料表、**工程量来源对照表**（预算工程量 ↔ S3 计算书条目 ↔ 图号）。
