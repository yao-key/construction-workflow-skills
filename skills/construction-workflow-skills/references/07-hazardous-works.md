# S4a 危大工程判定与专项方案补充

## 依据与禁令

依据住建主管部门《危险性较大的分部分项工程安全管理规定》及配套文件、天津市现行实施细则，以及图纸与施工组织设计判定危大工程（危险性较大的分部分项工程）。

**文号、具体阈值、规模分界、专家论证范围一律标「待核」，以现行有效文本为准**，不得凭记忆填写开挖深度、搭设高度、跨度、荷载等数值，也不得凭记忆写条文号。AI 输出为「疑似涉及 / 需人工判定」的初筛意见，最终判定由施工单位技术负责人、总监理工程师及建设单位按程序确认。

## 从图纸识别的判定信号（不是结论）

逐张扫描下列图纸信号，记录图号与部位，作为判定输入：

| 类别 | 图纸信号 | 常见图号来源 |
| --- | --- | --- |
| 基坑工程 | 地下室层数、基础埋深、基坑支护与降水、承台与集水坑深度、邻近既有建筑或管线 | 结施基础平面、总图、地勘资料 |
| 模板支撑 | 层高、梁板截面与跨度、悬挑构件、后浇带支撑、高大空间 | 结施梁板配筋平面、建筑剖面 |
| 起重吊装 | 预制构件、钢结构构件、大型设备基础与吊装口、塔吊与施工电梯布置 | 结施构件图、总平面 |
| 脚手架 | 檐口高度、外立面形式、幕墙与外装作业面 | 建施立面、剖面 |
| 拆除与改造 | 既有结构拆除、加固、托换、开洞补强 | 结施加固图、设计说明 |
| 其他 | 有限空间、暗挖、顶管、临近带电体、水上或地下作业 | 各专业说明与总图 |

判定原则：图纸「未见」不等于「不涉及」，写「未见相关表达，需结合施工组织设计确认」；深度、高度、跨度等阈值一律回查现行文件。

## 判定台账

复制 `assets/hazardous_works_register.csv`，逐项登记：编号、工程类别、部位与图号、图纸信号描述、是否疑似危大、是否疑似超过一定规模（需专家论证）、判定依据（文件名称，文号与阈值待核）、判定人、判定日期、确认状态、关联专项方案编号、论证状态。

状态流转：`待判定 → 疑似危大 → 已确认不涉及 / 已确认危大 → 方案已审批 → 已交底 → 已验收 → 已归档`。未判定项不得进入 S4 技术交底与现场实施；在 S2 会审中按 A 级问题提出。

## 若涉及：补充专项施工方案

专项方案按下列章节编制，缺项标「待补」，不得以「按规范施工」代替：

1. **工程概况**：危大工程部位、图号、规模参数（按图）、周边环境与地下管线、施工平面布置
2. **编制依据**：图纸图号与版本、现行法规与规范名称（文号与条文号待核）、施工组织设计、计算所依据的参数来源
3. **施工计划**：进度、材料与设备、劳动力、进场验收
4. **施工工艺技术**：技术参数、工艺流程、施工方法、检查验收节点与标准
5. **施工安全保证措施**：组织保障、监测监控、技术措施、应急处置、季节性措施
6. **劳动力计划**：专职安全管理人员、特种作业人员及持证要求
7. **计算书及相关图纸**：模板支撑、基坑支护、吊装、临时用电等计算书与节点图；**计算书须由具备相应资格的人员编制并复核，AI 只做资料整理、索引与格式核对，不出具承载力、稳定性结论**
8. **应急处置**：风险源、预警值、响应流程、物资与联络方式

## 审批与实施流程

施工单位技术负责人审核签字 → 总监理工程师审查 → 建设单位项目负责人签认 → 超过一定规模的按现行规定组织专家论证并按论证意见修改完善 → 方案交底与安全技术交底 → 按方案实施与过程巡视监测 → 分阶段验收 → 资料归档。审批、论证、交底、验收记录全部进入 S5 移交清单。

方案编制与审批用印、签字、日期栏留空由责任主体填写，AI 不代签。

## 与安全管理的关系

危大工程是 `08-safety-management.md` 安全管理重点的子集且优先级最高：先完成本篇的判定与专项方案，再编制一般安全管理措施；专项方案未审批时，对应部位不得列入可施工范围。
