# S4b 安全管理重点与措施

## 定位

从图纸与施工组织条件中识别安全管理重点，形成「部位—风险—措施—检查—责任」闭环清单。危大工程（见 `07-hazardous-works.md`）是其中的高优先级子集，须先完成专项方案审批。

**数值禁令**：防护栏杆高度、洞口覆盖尺寸、临边距离、荷载限值、安全距离、验收允许偏差等具体数值一律按图纸或现行有效规范文本填写，缺失时标「待核」，不得凭记忆填写，也不得编造条文号。

## 从图纸识别重点部位

逐张扫描并记录图号与轴线位置：

| 部位/作业 | 图纸信号 | 主要风险 |
| --- | --- | --- |
| 基坑与基础 | 基础埋深、支护、降水、集水坑、邻既有建筑 | 坍塌、涌水、周边沉降、临边坠落 |
| 洞口与临边 | 楼板预留洞、电梯井、管井、楼梯口、屋面女儿墙、阳台 | 高处坠落、物体打击 |
| 高处作业 | 层高、檐口高度、外立面、幕墙、屋面坡度 | 坠落、落物、脚手架与操作平台失稳 |
| 模板支撑 | 高支模区域、大跨度梁、悬挑、后浇带 | 架体失稳、坍塌、超载 |
| 起重与机械 | 预制构件、钢结构、塔吊/施工电梯位置、吊装口 | 倾覆、吊物坠落、机械伤害 |
| 临时用电 | 配电房、电缆沟、设备容量（电气图） | 触电、电气火灾 |
| 消防与动火 | 防火分区、疏散通道、易燃材料堆放、焊接作业 | 火灾、烟气中毒 |
| 有限空间 | 地下室集水坑、管井、水池、检查井 | 中毒窒息、盲目施救 |
| 季节性 | 天津地区冬季、雨季、大风及高温时段 | 冻害、基坑积水、架体风载、中暑 |
| 交叉作业 | 多专业同一作业面、垂直运输与下方通道 | 物体打击、工序互相破坏 |

图纸未表达但现场存在的风险（如临时设施、运输道路）标「现场条件待确认」，由项目安全员补充，不写「无风险」。

## 措施四层结构

每个重点部位按四层写全，缺层标「待补」：

1. **技术措施**：防护设施做法、构造要求、材料规格、验收标准（数值待核）、图示索引
2. **管理措施**：责任岗位、作业审批、班前教育与交底、持证要求、作业许可、旁站与监护
3. **检查验收**：检查项、频次、检查人、记录表、不合格处置与复查闭环
4. **应急处置**：预警信号、撤离路线、物资、联络方式与演练要求

危大部位额外注明「按专项方案执行」并填入专项方案编号。

## 输出成果

- **安全管理重点与措施表**：复制 `assets/safety_control_plan_template.md`，字段含编号、部位、图号、风险描述、风险等级、技术措施、管理措施、检查验收、应急处置、责任人、专项方案编号、状态
- **安全技术交底**：与 `04-deliverables.md` 的技术交底分开编制，面向作业班组，按工种与作业段分别成文；参数后括注依据图号
- **安全检查表**：按检查频次（日常、周、专项、季节、节前）分别列项，附整改闭环栏
- **应急预案要点**：风险源清单、响应流程、物资与联络表，正式预案须由项目技术负责人审批

## 与既有流程的衔接

- S2 会审：涉及安全的图纸矛盾按 A 级问题提出，未闭环不得进入交底
- S4 技术交底：安全交底作为独立文件随技术交底一并签发，两者互相引用编号
- S4a 危大工程：专项方案未审批的部位从「可施工范围」中剔除
- S5 归档：重点清单、安全交底、检查与整改记录、专项方案及论证资料、应急演练记录列入移交清单

## 责任边界

成果为 AI 辅助编制的安全管理初稿，须由项目技术负责人、专职安全员及相应责任主体复核签认；不替代专项施工方案、法定验收、安全检查记录与应急预案审批。
