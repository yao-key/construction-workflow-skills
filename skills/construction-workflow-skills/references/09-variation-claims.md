# S4c 签证管理

## 概念区分（不得混用）

| 类型 | 发起方 | 改变对象 | 主要文件 |
| --- | --- | --- | --- |
| 设计变更 | 设计单位 | 图纸与技术要求 | 设计变更通知单、变更令、修改图 |
| 工程洽商 | 建设/施工/设计/监理协商 | 做法、范围或条件 | 洽商记录、技术核定单 |
| 现场签证 | 施工单位提出、建设与监理确认 | 现场事实、工程量、费用与工期 | 现场签证单、影像与测量记录 |
| 索赔 | 合同一方按合同程序 | 合同价款与工期 | 索赔意向通知、索赔报告 |

同一事项不得重复计列：已由设计变更或合同价款覆盖的内容不得再办签证；台账中登记关联变更令编号以查重。

## 常见触发情形

图纸与现场条件不符、隐蔽工程覆盖前确认、合同外零星用工与零星工程、停窝工、材料代换与规格变更、不可抗力与异常天气、超出合同范围的口头或书面指令、工程量增减、施工条件变化导致的措施调整、图纸会审中暂估项落地。

## 办理流程（九步）

1. **事件发生**：记录时间、部位、图号、指令来源与在场人员
2. **及时通知**：按合同约定期限书面通知监理与建设单位；口头指令须当日形成书面记录请对方确认
3. **现场取证**：影像（含时间、部位标识）、测量记录、旁站或见证记录、会议纪要、材料进场与验收记录；隐蔽工程覆盖前必须完成
4. **一事一签**：填写签证单，事由、事实、工程量、计价方式、工期影响分栏写，不合并多事项
5. **核量核价**：工程量回指图号或现场测量记录；计价方式按合同约定，费用与工期分别确认
6. **签认**：由有授权的建设单位代表、监理工程师签字并注明日期；签字人资格与授权范围核对，AI 不代签
7. **计价**：按 `06-tianjin-budget.md` 的口径进入预算调整版
8. **台账归档**：原件、附件、影像编号归档，登记状态
9. **回写联动**：更新 S0 图纸台账与作废关系、标记 S3 计算书受影响分项「需重算」、更新预算、相关技术交底与安全交底标记「需重新交底」、列入 S5 移交清单

## 时效与证据原则

- **先确认后实施**：除抢险等应急情形外，未签认不得作为结算依据；应急情形须在事后按合同期限补齐手续并记录原因
- **一事一签、当日或合同约定期限内办理**，不得事后集中补签；超期事项单列「超时效风险」并说明
- **证据链完整**：签证单、指令、影像、测量记录、会议纪要、材料凭证编号互相引用
- **只签事实不签费用的**，在台账中标记「费用待核」，不得自行推算金额
- **原件留存**，复印件标注与原件一致；电子影像保留原始文件与拍摄时间

## 计价口径（与天津市定额衔接）

有适用定额子目的按子目套用；无适用子目的按合同约定的协商价或市场询价并经确认；人材机价差与取费按合同及天津市现行文件。**子目编号、基价、费率、信息价期号一律标「待核」**，以本地现行有效文本为准（见 `06-tianjin-budget.md` 与 `05-closeout-and-standards.md`）。工程量必须能回溯到图号、变更令或现场测量记录，不得用估算值直接计价。

## 签证台账

复制 `assets/variation_claim_register.csv`，字段：编号、发生日期、部位与图号、事由摘要、依据类型（变更令/指令/洽商/纪要）、关联变更令编号、工程量、计量依据、计价方式、金额（含待核标记）、工期影响、签认方与授权状态、状态、附件清单、预算回写状态、交底更新状态、归档编号。

状态流转：`发生 → 已通知 → 已取证 → 已签认 → 已计价 → 已回写 → 已归档`；任一环节缺失时停在对应状态并列入未决事项，不得静默跳过。

## 常见风险与检查点

| 风险 | 检查动作 |
| --- | --- |
| 口头指令无书面记录 | 核对当日往来函件与会议纪要 |
| 重复签证 | 与变更台账、合同价款、已结算项查重 |
| 隐蔽工程未及取证 | 核对影像时间与覆盖验收记录 |
| 签字人无授权 | 核对授权文件与签字样张 |
| 附件缺失或编号不互引 | 逐项核对附件清单 |
| 只签事实未签费用 | 标记「费用待核」，不进入汇总 |
| 未回写算量与预算 | 核对 S3 计算书与预算调整版的回写状态 |

## 责任边界

签证成果为 AI 辅助的台账与文件初稿，费用与工期须按合同程序由建设、监理、施工各方签认，并由造价人员复核；不替代合同约定的签证、索赔与结算程序。
